# Realms 0.4

- Fixed the mature-world road lattice. Walking counts no longer become roads. Stored reciprocal edges define real street junctions; branch roads join the existing network once. Corners are rounded, and new parcels no longer follow a reserved six-cell grid. Old saves repair street geometry once without replacing people, buildings, terrain or inventories.
- Restored MAX alongside fixed speeds. MAX has no simulated-days or tick-count target and runs as many exact ticks as possible in each time slice, yielding for drawing/input. It remains one deterministic simulation thread; it is not an all-core parallel solver. Modal dialogs, pause and hidden-tab behavior remain respected.
- Added 8 resources (19 total), 8 producer types and 6 practical discoveries (36 total). Fisheries require a real river/coastal bank and deplete a renewing fish stock. Wheat and flax have actual crop/harvest states. Mills, bakeries, clay yards, kilns and weaving sheds have workers, inputs and outputs. Bricks feed dense housing; cloth feeds winter warmth and machinery. Intercity markets can transport the added goods.
- Added a Supply inspector with chains, input counts, workers and blocked reasons. Existing recipes retain the communal-stock abstraction.
- Added six editable parameters: average temperature, rainfall, storm and drought frequency, fertility and forest cover. Apply climate to a running world or choose parameters before creating one. Existing towns and people are preserved. Forest density changes new terrain; live forest changes affect regrowth.
- Added persistent humans, elves, dwarves and orcs in shared settlements, mixed-species parentage and heritage, population counts and species appearance. Equal access to work/housing/food remains the default.
- Added latitude/elevation climatology, polar ice/tundra, taiga, temperate/tropical forests and dry biomes. Both poles are colder than the equator; hemisphere seasons oppose. Climate affects crops, warmth, fish recovery, vegetation, spoilage and new forest density. New river channels trace descending local drainage rather than a fixed sine wave.
- Added a space/city zoom-and-fade transition, scroll-in/out navigation and reduced-motion behavior. The maps remain separate views, not seamless planetary terrain.

Older v2/v3 saves remain loadable. New resources initialize to zero, missing species/planet metadata is added deterministically, and original stockpiles and individuals are retained. Existing terrain is preserved; new drainage is created for new settlements. The previous century checkpoint remains a legacy-ruleset fixture. `saves/realms-seed-481217-after-30-years.json` is a fresh natural Realms checkpoint.

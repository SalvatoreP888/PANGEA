The PANGEA contribution is original: a read-only identity derivation module, typed contract, a settlement shield and profile component, architectural summary helper, and regression tests. These files use the project's MIT license. The shield is explicitly a derived decorative emblem, and it asserts no historical lineage. Same-name resident groups never imply shared ancestry; specialization identifies recorded workshop batches rather than prosperity or invented lore. Architecture reflects completed housing and installed beds. Events retain source id/day/title/detail and town association. The event log is bounded, so profiles describe retained milestones rather than an exhaustive history. Existing saves need no migration.

No upstream patch or communication has been sent. A potential upstream documentation contribution would clarify the v21 package's license chain; it remains a suggestion, not a claimed contribution.
